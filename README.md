# Foootie website

Holding page for Foootie (foootie.co.uk redirects here). Plain static HTML, served by GitHub Pages from `main`.

- Phones see the App Store / Google Play button for their platform (plus a play-in-browser link).
- Laptops and desktops see **Play now**, which opens the web app at https://foootie.github.io/foootie/.
